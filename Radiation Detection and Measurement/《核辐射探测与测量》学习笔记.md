# What

## 定义

### 原子核激发

原子核内部的质子和中子组成的核系统，处于一些特定的能量状态。

核能量
  ↑
  │       ─────────  激发态 E*
  │          ↓
  │          ↓ γ
  │       ─────────
  │
  │       ─────────  基态 E₀
  │
  └────────────────

最低能量状态叫：
$$
\boxed{\text{基态（ground state）}}
$$
高于基态的核能量状态叫：
$$
\boxed{\text{激发态（excited state）}}
$$
如果核处于激发态，它通常是不稳定的，会通过各种方式释放多余能量，回到较低能级。

### 原子激发



### γ射线

伽马射线是由**受激原子核**在向低级核转变过程中发射的。伽马射线能量反映了子核的能级结构。伽马射线几乎都是单能的。伽马射线通常也是在典型原子核吸收热中子（能量很低的中子）后发射的。

γ 射线的产生过程发生在**原子核内部**：

1. **激发态原子核**：当原子核发生 α 衰变或 β 衰变后，新生成的原子核往往处于能量较高的“激发态”（不稳状态）。
2. **退激发放能**：为了回到稳定的“基态”，原子核需要释放掉多余的能量。
3. **释放γ光子**：这部分多余的能量就会以一个高能光子的形式被扔出来，这个过程就是 **γ 跃迁**（或称 γ 衰变）。

因为原子核内部的能级间隔非常大，所以释放出的光子能量极高（远高于可见光、紫外线甚至医用 X 射线），这赋予了γ 射线极强的**穿透力**。

### 特征X射线

内层电子被打出后，外层电子向内层填补跃迁时释放的**特定能量的光子**。

### 核外电子层级的定义和命名规则

一、 四大量子数与层级定义

决定核外电子运动状态和能量分布的四个量子数：

1. 电子层（Main Shells）

- **定义**：描述电子距离原子核的平均远近以及能量高低的主要层级。
- **符号/量子数**：由**主量子数 n** 决定（取正整数：n = 1, 2, 3, 4, 5, 6, 7, ...）。
- **命名规则**：从紧靠原子核的最内层开始，分别用大写字母 **K, L, M, N, O, P, Q** 命名：
  - n = 1 -> **K 层**（能量最低，离核最近）
  - n = 2 -> **L 层**
  - n = 3 -> **M 层**
  - n = 4 -> **N 层**（以此类推）
- **容量限制**：第 n 个电子层最多可容纳 **$2n^2$** 个电子。

> **历史趣闻（为什么从 K 开始命名？）**：
>
> 1900 年代，物理学家查尔斯·巴克拉（Charles Barkla）在研究元素发出的特征 X 射线光谱时，为了给未来的发现留出空间，从字母表中段选取了 **K** 和 **L** 来标记光谱线。后来这一命名被直接保留并应用到了电子壳层的标记上。

2. 电子亚层（Subshells）

- **定义**：在同一个电子层内部，由于电子运动的角动量不同，能量还存在微小差异，由此划分出的子层级。它决定了**电子云的空间形状**。
- **符号/量子数**：由**角量子数 $l$** 决定。对于给定的 $n$，$l$ 的取值为 $0, 1, 2, \dots, n-1$（共 $n$ 个亚层）。
- **命名规则**：习惯上使用小写字母 **s, p, d, f, g, h...** 标记：
  - $l = 0$ $\rightarrow$ **s 亚层**（*sharp*，球形电子云）
  - $l = 1$ $\rightarrow$ **p 亚层**（*principal*，哑铃形/纺锤形）
  - $l = 2$ $\rightarrow$ **d 亚层**（*diffuse*，花瓣形）
  - $l = 3$ $\rightarrow$ **f 亚层**（*fundamental*，更复杂的空间分布）
  - $l = 4, 5 \dots$ $\rightarrow$ **g, h...**（按字母顺序顺延）
- **书写方式**：主量子数 + 亚层字母，例如 **$1\text{s}$**（第 1 层的 s 亚层）、**$2\text{p}$**、**$3\text{d}$**。

3. 原子轨道（Atomic Orbitals）

- **定义**：亚层在空间中的不同伸展方向（空间取向）。
- **符号/量子数**：由**磁量子数 $m_l$** 决定。取值范围为从 $-l$ 到 $+l$ 的整数（共 $2l + 1$ 个取向）。
- **轨道数量与电荷容量**：
  - **s 亚层**（$l=0$）：$1$ 个轨道，最多存 $2$ 个电子。
  - **p 亚层**（$l=1$）：$3$ 个轨道（如 $\text{p}_x, \text{p}_y, \text{p}_z$），最多存 $6$ 个电子。
  - **d 亚层**（$l=2$）：$5$ 个轨道，最多存 $10$ 个电子。
  - **f 亚层**（$l=3$）：$7$ 个轨道，最多存 $14$ 个电子。

4. 电子自旋（Electron Spin）

- **定义**：电子本身的内秉角动量方向。
- **符号/量子数**：由**自旋磁量子数 $m_s$** 决定，只有两个可能的值：**$+\frac{1}{2}$**（自旋向上，通常记作 $\uparrow$）和 **$-\frac{1}{2}$**（自旋向下，通常记作 $\downarrow$）。

二、 电子排布三大基本原理

核外电子在各个轨道中的填装遵循以下物理规律：

1. **能量最低原理（Aufbau Principle）**：电子优先占领能量最低的轨道。但在高层数时会出现“**能级交错**”现象，如能量上 $4\text{s} < 3\text{d}$，因此电子会先填满 $4\text{s}$ 再填入 $3\text{d}$。
2. **保里不相容原理（Pauli Exclusion Principle）**：同一个原子中，**不可能有两个电子拥有完全相同的四个量子数**。这意味着**每个轨道最多只能容纳 2 个电子，且这两个电子的自旋方向必须相反**。
3. **洪特规则（Hund's Rule）**：电子在填入简并轨道（同亚层中能量相同的不同轨道）时，会优先以相同的自旋方向分占不同的轨道，以使总自旋最大化、体系能量最低。

### 能谱

**能谱（Energy Spectrum）**，简单来说，就是**辐射（或粒子）按照“能量大小”分布的一幅“统计直图”**。如果把辐射想象成一群不同身高的人，那“能谱”就像是把这群人按身高从矮到高排队，并统计“每个身高区间里有多少人”所画出的统计图表。

一、 **怎么直观理解能谱**？

在核物理、辐射测量或医学成像中，探测器测量到的辐射通常包含成千上万个光子或粒子。能谱图通常有两个轴：

- **横坐标（X轴）—— 能量（Energy）：** 代表光子或粒子的能量高低（常用单位如
  $$
  \text{eV}、\text{keV}、\text{MeV}
  $$
  ）。从左到右，能量依次增大。

- **纵坐标（Y轴）—— 数量/强度（Intensity / Counts）：** 代表在该特定能量下，探测器收到了多少个光子或粒子（即出现的频率或概率）。

通过能谱图，你能一目了然地看出：**这次辐射中，哪些能量的光子最多？哪些能量的光子很少？**

**二、 能谱的两大基本形态**

根据产生辐射的物理过程不同，能谱主要分为两类：

1. **线状谱 / 离散谱（Line / Discrete Spectrum）**

- **形状：** 图上呈现为一根根孤立的、像针一样的“尖峰”（也称单能峰）。
- **物理机制：** 来自于量子的“能级跃迁”。例如原子核从一个固定的激发态跃迁到基态，释放出的 γ 光子能量是绝对固定的（如 ${}^{60}\text{Co}$ 释放的 $1.17\text{ MeV}$ 和 $1.33\text{ MeV}$ 光子）。
- **作用：** 就像“元素的指纹”。看到特定能量的尖峰，就能直接断定源头是什么核素。

2. **连续谱（Continuous Spectrum）**

- **形状：** 图上呈现为一条平滑连接的曲线，像一座连绵的山丘。
- **物理机制：** 来自于能量可以连续变化的物理过程。例如：
  - **β 衰变：** 衰变释放的能量由电子和中微子共同随机分担，导致测到的电子能量是连续分布的。
  - **轫致辐射（Bremsstrahlung）：** 高速电子在原子核电场中减速，可以损失任意比例的能量，产生从 $0$ 到最大动能连续分布的光子。

**三、 生活与科研中的能谱应用**

1. **核素识别（伽马能谱仪）：**

   在机场安检、环境监测或核医学中，通过测量未知放射源的 $\gamma$ 能谱，对比谱图上的尖峰位置，就能知道它到底是医学用的 ${}^{99m}\text{Tc}$、工业用的 ${}^{137}\text{Cs}$，还是危险的裂变产物。

2. **医学 X 光与 CT 检查：**

   医院 X 光机发出的就是连续的轫致辐射能谱。医生需要通过调整管电压来改变 X 射线的能谱分布，以获得既清晰又对人体辐射剂量最小的诊断图像。

3. **天文观测：**

   天文学家接收来自遥远恒星或黑洞周围的 X 射线/伽马射线能谱，就能推算出那个天体的温度、密度以及包含什么化学元素。

### 荧光产额

**荧光产额（Fluorescent Yield,ω）：** 定义为**处于激发态的原子在退激发时发射特征 X 射线光子的概率/比例**。   

- 对于轻元素（小 $Z$），俄歇效应占主导，荧光产额低；
- 对于重元素（大 $Z$），特征 X 射线发射占主导，荧光产额高（接近 1）。

## β衰变

### 内转换电子和俄歇电子的区别

内转换电子（Internal Conversion Electron）和俄歇电子（Auger Electron）都是原子核或原子体系释放能量时从**核外电子壳层**中发射出来的电子，但它们的**能量来源、产生机制及物理过程**有着本质区别：

| **比较维度** | **内转换电子（Internal Conversion Electron）**               | **俄歇电子（Auger Electron）**                               |
| ------------ | ------------------------------------------------------------ | ------------------------------------------------------------ |
| **能量来源** | **原子核内**的激发态跃迁退激能量                             | **核外电子壳层**的电子跃迁能量                               |
| **物理机制** | 核内激发能量直接传递给核外内层电子（主要为 $K, L$ 壳层），使其克服结合能脱离原子。 | 原子的内层空穴被外层电子填补时，释放的能量未以 X 射线形式辐射，而是直接传递给另一个外层电子并将其抛出。 |
| **直接诱因** | $\beta$ 衰变或 $\gamma$ 跃迁后，原子核处于激发态（退激过程）。 | 原子内层形成了**电子空穴**（可由内转换、轨道电子抓获或外部射线击穿产生）。 |
| **能量计算** | $E_e = \Delta E_{\text{核}} - B_e$ （$\Delta E_{\text{核}}$ 为核能级差，$B_e$ 为电子结合能） | $E_e = (E_{K} - E_{L1}) - E_{L2}$ （依赖于相关三个电子壳层的结合能差） |
| **能谱特征** | **线状谱（单能）**，反映的是核能级的结构特征。               | **线状谱（单能）**，但能量通常较低，反映的是原子的电子壳层结构。 |

**详细过程解析**

1. **内转换电子（与核能级直接相关）**
   - 当原子核经历 $\beta^-$ 或 $\beta^+$ 衰变后，往往会留在激发态。
   - 原子核退激时，除了可以发射 $\gamma$ 光子外，还可以通过电磁相互作用直接将能量交给核外电子（主要是离核最近的 $K$ 壳层电子）。
   - 这种电子被喷射出来即为**内转换电子**。内转换电子发射后，该原子核的能量降低，但**核内电荷和质量均不改变**，同时在原子 $K$ 壳层留下一个**电子空穴**。
2. **俄歇电子（与核外电子壳层重排相关）**
   - 当内转换电子（或电子抓获等过程）离开原子后，内层（如 $K$ 壳层）留下了空穴。
   - 更外层（如 $L$ 壳层）的电子会自发向内跃迁来填补这个空穴。
   - 跃迁释放的能量有两个去向：
     1. 以特征 X 射线（Fluorescent X-ray）的形式辐射出去；
     2. 将能量无辐射地交给另一个更外层的电子（如另一个 $L$ 壳层电子），使其被抛出原子——这就是**俄歇电子**。

**总结**

简单来说，**内转换电子是“核能量”直接作用于核外电子的结果**，是核退激的一种表现形式；而**俄歇电子则是“壳层空穴被填补”时引发的继发效应**，是核外电子层自我调整与重排的结果。在含有内转换过程的 $\beta$ 衰变链中，通常是**先产生内转换电子，随后因留下空穴而伴随产生俄歇电子或特征 X 射线**。

## α衰变

### 势垒穿透机制

**原理**：依据经典力学，当 $\alpha$ 粒子的能量低于母核静电库仑势垒的高度时，$\alpha$ 粒子无法穿越势垒。但量子力学中的**量子隧穿效应**允许具有波粒二象性的 $\alpha$ 粒子以一定的概率穿过该势垒。   

**与半衰期的关系**：穿透概率对 $\alpha$ 粒子的能量极度敏感。$\alpha$ 粒子的能量越低，穿透概率越小，母核的半衰期就越长；能量越高，半衰期越短。

### α衰变纲图

展现母核衰变到子核不同量子能级（如基态和各激发态）的过程。例如图 1.3 中，$^{238}\text{Pu}$ 衰变时，既可以衰变到 $^{234}\text{U}$ 的基态（$0\text{ MeV}$），也可以衰变到其激发态（$0.043\text{ MeV}$、$0.143\text{ MeV}$）。

### α衰变预期能谱

由于对应着不同的衰变分支（跃迁），能谱上会出现若干个孤立的尖峰（如图中所示的 α1, α2, α3），每个峰的面积代表该分支的衰变概率（分支比）。

### 反冲核

**定义**：在α粒子被发射出去的同时，由于动量守恒，子核（即质量数为 A-4 的新原子核）会被向相反方向“推”出去，这个运动的子核就是反冲核。

**能量分配**：反冲核带走了一小部分衰变能，即 
$$
E_{\text{recoil}} = Q \cdot \frac{4}{A}
$$
因为 A >> 4，绝大部分能量都被轻巧的 α 粒子带走。

## 自发裂变

重核（如超铀元素）在没有任何外来粒子轰击的情况下，自行分裂成两个中等质量的碎片，并释放出高能重粒子和快中子的过程。这是唯一能产生质量大于 α粒子的天然/自发高能重粒子源。

自发裂变主要是**不对称裂变**，分裂出的两个碎片一轻一重，质量数呈双峰分布：   

- **轻碎片组**：平均质量数约为 108。   
- **重碎片组**：平均质量数约为 143。

## 电磁辐射源

### 湮灭辐射

当母核发生β+衰变时，会放射出正电子（Positron）并产生额外的电磁辐射。正电子在介质中的射程极短（通常只有几毫米），在此期间它会迅速损失动能。

当正电子的能量降低到非常低的水平（接近其射程末端）时，它会与吸收介质中的普通负电子（Negative Electron）结合。在此过程中：   

- 原始的正电子与负电子双双**消失（湮灭）**。   
- 正负电子的静止质量完全转化为电磁能量，产生两个**方向相反（飞行方向呈 180°）**、能量均为 **0.511MeV** 的电磁光子，这就是**湮灭辐射**。

这种 0.511MeV 的湮灭光子会叠加在子核后续衰变所发射的任何原生伽马射线谱上。

### 轫致辐射

1. 物理本质定义

> **定义：** 轫致辐射是指**高速带电粒子在物质的电场中受库仑力作用急剧减速或偏转时，将其部分或全部动能转化为连续电磁辐射（光子）释放的过程**。

2. 作用机制定义

> **定义：** 当带电粒子（主要是电子或正电子）穿过靶物质时，受原子核库仑电场的强力吸引或排斥而发生轨迹弯曲与减速。根据电动力学原理，**加速/减速中的带电粒子必然会发射电磁波**，这种由“刹车制动”过程产生的连续电磁光谱即称为轫致辐射。

关键特征解析

1. **产生的辐射类型：**

   - 低至中等能量的带电粒子产生的是 **X 射线**（如医用 X 射线管中电子轰击钨靶产生的连续 X 射线）。
   - 高能带电粒子（如几十 MeV 甚至更高）产生的则是高能 **γ 射线**（如高能电子加速器轰击重金属靶产生的高能连续光子）。

2. **连续光谱特征：**

   - 轫致辐射产生的光子能谱是**连续谱**（从接近 0 一直连续延伸到带电粒子的最大初始动能 T_{max}），而不是像核退激发那样产生离散的“单能峰”。

3. **与粒子质量的关系（轻粒子最显著）：**

   - 根据经典电动力学，轫致辐射强度与带电粒子质量的平方成反比
     $$
     \propto \frac{1}{m^2}
     $$

   - 因此，质量极轻的**电子**和**正电子**发生轫致辐射的概率和强度极高；而质量很大的**重带电粒子**（如 α 粒子、质子）发生轫致辐射的能量损失几乎可以忽略不计。

# Why

### 衰变名称命名规则

在1899年前后，物理学家欧内斯特·卢瑟福（Ernest Rutherford）等人在研究铀等放射性元素时，发现放射线可以被电磁场偏转，并且穿透力各不相同：

- 穿透力最弱、能被一张纸挡住的射线，被顺手命名为 **α 射线**（第一个希腊字母）。
- 穿透力较强、能穿透薄铝片的射线，被命名为 **β射线**（第二个希腊字母）。
- 穿透力极强、能穿透厚铅板的，后来被命名为 **γ射线**。

当时科学家们只知道这是某种“射线”，**完全不知道它们的微观组成**。等多年后卢瑟福和他的同僚通过实验证实 β 射线就是高能电子流、α 粒子就是氦核时，α 和 β 的叫法已经在科学界广泛沿用并写入教科书了。

即使后来知道了它们的身份，物理学家依然倾向于保留 $\alpha$ / $\beta$ 衰变这种称呼，因为直接叫“电子衰变”或“氦衰变”在物理上不够精准：

- **$\alpha$ 衰变释放的是“氦原子核”，而不是“氦原子”**

  $\alpha$ 粒子是含有 2 个质子和 2 个中子的**高能氦-4原子核（$\text{He}^{2+}$）**，它是不带核外电子的。如果叫“氦衰变”，容易让人误以为是释放出了一个完整的中性氦原子。

- **$\beta$ 衰变里的电子不是原子核里原本就有的**

  如果在核外发生的物理过程释放了电子，我们通常叫“电子发射”。但 $\beta^-$ 衰变是**原子核内部的中子发生了弱相互作用**，衰变成了质子、电子和反中微子：

  $$
  n \to p + e^- + \bar{\nu}_e
  $$
  这个电子是**在衰变瞬间凭空产生**并被高速抛出的，并非原子核“原本藏着一个电子把它扔出来”。
  
  此外，$\beta$ 衰变还包含 $\beta^+$ 衰变（释放**正电子**），叫“电子衰变”无法准确涵盖正电子衰变的情况。

为了体现这种“来自原子核内部弱相互作用或强相互作用引发的高能粒子放射”，物理学界便继续沿用了 $\alpha$ 和 $\beta$ 衰变这两个经典名称。

### α粒子的发射能量是单能组

α衰变属于**两体衰变**（反应产物仅有子核和 α 粒子两个粒子）。根据**能量守恒**和**动量守恒**，衰变释放的总能量 Q 在两个产物之间的分配方式是唯一确定的：  

**动量守恒**：α 粒子与反冲核动量大小相等、方向相反
$$
p_\alpha = p_{\text{recoil}}
$$
**能量分配**：总衰变能 Q 分配为两者的动能
$$
Q = E_\alpha + E_{\text{recoil}}
$$
**公式导出**：结合动能表达式 
$$
E = \frac{p^2}{2m}
$$
​	可推出 α粒子的动能为：
$$
E_\alpha = Q \cdot \frac{A - 4}{A}
$$
​	其中 A 为母核的质量数。对于特定的能级跃迁，Q 值是固定常数，因此 α 粒子获得的能量也是**严格确定且单一的**。

### 标准发射源

标准发射源（标定源）主要用于以下核心需求：

- **探测器能量与道数校准**：探测器输出的原始信号通常是电荷或电压脉冲（如 MCA 多道分析器的道数），需要已知确切能量的标准源来建立“信号幅度/道数-能量”的定量对应关系。
- **测量能量分辨率与探测效率**：通过标准源发出的已知能量和分支比的粒子，评估探测器区分相近能量的能力（分辨率），以及检测特定能量粒子的概率（几何与本征效率）。
- **校正死层与能量损失**：粒子在进入探测器灵敏区前会穿过窗口或死层，标准源可以帮助精确测定并补偿这部分能量损失。

### 衰变后子核处于激发态

1. **衰变中的选择定则**（Selection Rules）

衰变过程受量子力学角动量守恒和宇称守恒的严格限制。

- **角动量与宇称的匹配：** 母核和子核基态之间的角动量（自旋 $I$）及宇称（$\pi$）差异可能很大。如果从母核直接衰变到子核的**基态**，需要带走很大的角动量（即轨道角动量 $L$ 很高），或者要求发生宇称改变。
- **跃迁概率下降：** 携带高角动量的粒子逸出（或发生衰变）的概率会随着角动量 $L$ 的增大而**指数级下降**（例如 $\alpha$ 衰变中的离心势垒阻碍，或 $\beta$ 衰变中的禁戒跃迁）。因此，衰变倾向于选择衰变到角动量和宇称与母核更接近的**子核激发态**，因为这种跃迁的速率更快、更容易发生。

2. **能级结构与波函数重叠**（结构相似性）

**衰变本质上是核内核子排列结构的重组**。

- 母核与子核的**基态**在结构上（例如形变、核子占据的轨道）可能差异很大。
- 相比之下，子核的某个**激发态**在波函数形式或空间结构上可能与母核的基态更为相似（重叠积分大）。根据量子力学的微扰理论，这种结构相似的跃迁矩阵元更大，衰变到该激发态的概率（分支比）也更高。

3. **反冲效应与核内剩余能量**

衰变过程中释放的总能量（$Q$ 值）非常大。

- 当轻粒子（如 α 粒子、β 粒子或中微子）被高速高速抛出时，由于动量守恒，子核会受到反冲。
- 衰变瞬间核内核子的自由度受到扰动，释放的能量并不总是能完全以发射粒子的动能形式带走，部分能量会残留在子核内部，使核子处于激发构型（即处于更高的能级）。

后续过程

由于处于激发态的子核是不稳定的，它通常会在极短的时间内（通常在 $10^{-12} \sim 10^{-9}\text{ s}$ 内）通过**发射 γ 射线**或发生**内部转换（Internal Conversion）**，将多余的激发能释放出来，退激发落回子核的基态。这也是为什么许多 $\alpha$ 或 $\beta$ 放射源同时伴随有特定能量的 $\gamma$ 射线辐射的原因。

###  α 辐射源实测能量峰比标称能量偏低

$$
E_{\text{测}} = E_{\text{标称}} - \Delta E_{\text{自吸收}} - \Delta E_{\text{薄膜/死层}} - \Delta E_{\text{介质空气}}
$$

### 光子的能量会因多普勒效应而变宽

1. 核心原因：发射光子的原子核处于运动状态（具有反冲速度）

根据图片文本描述，在核反应 
$$
{}^4_2\alpha + {}^9_4\text{Be} \rightarrow {}^{12}_6\text{C}^* + {}^1_0\text{n}
$$
中，产生的激发态碳核 
$$
{}^{12}\text{C}^*
$$
 获得了极高的**反冲速度（Recoil Velocity）**。   

由于该激发态的平均寿命极其短暂（仅约为 **61 fs**）：   

- 碳核在来不及通过与周围介质碰撞减速停下来（Come to rest）之前，就已经退激发并放射出了 4.44 MeV 的 γ 光子。   
- 这意味着 γ 光子是由一个正在高速运动的“光源”（反冲碳核）发射出来的。   

2. 多普勒效应如何导致能量改变

根据经典/相对论多普勒效应，当波源（原子核）以速度 v 运动时，观察者（探测器）接收到的光子频率 $\nu$以及对应的光子能量 
$$
E_\gamma = h\nu
$$
取决于**核的运动方向与光子发射方向之间的相对夹角 θ**：   
$$
E_{\text{测}} \approx E_0 \left( 1 + \frac{v}{c} \cos\theta \right)
$$


- **朝向探测器运动（θ=0°）：** 光子发生蓝移，探测器测得的能量偏高（E > E_0）。   
- **背向探测器运动（θ=180°）：** 光子发生红移，探测器测得的能量偏低（E < E_0）。   
- **垂直方向运动（θ=90°）：** 能量接近固有能量 $E_0$。   

3. 为什么是“展宽（Broadened）”而不是单纯的偏移？

在实际反应中，大量反冲碳核的**速度方向（以及方向与探测器的夹角 θ）是各向异性或随机分布的**：   

1. 探测器接收到的不同光子，是由朝不同方向运动的碳核发射的。   
2. 这导致部分光子能量偏高、部分光子能量偏低，连续分布在标称值附近。   
3. 最终在光谱仪上呈现出的结果，就是**原本极细的单能 γ 峰被“拉宽”成了一个具有约 1% 固有线宽的宽峰**。   

总结

这就是所谓的**多普勒展宽（Doppler Broadening）**：由于反冲核在发射光子时尚未停稳，不同方向运动的核通过多普勒效应给光子带来了不同的频移/能移，大量光子叠加后便使整体测量峰变宽。对于高能量分辨率的探测器（如高纯锗探测器），这种展宽会非常明显。

### β衰变的能谱是连续的

1. 两体衰变 vs 三体衰变

- **两体衰变（以 α 衰变或 γ 跃迁为例）：**

  - 反应产物只有**两个**（如：子核 + α 粒子）。
  - 根据动量守恒和能量守恒定律，两个产物的运动方向必须相反，且各自获得的动能是被**完全确定（固定）\**的。因此，测得的粒子能量只能是一个或几个固定的数值，表现为\**单峰/线状谱**。

- **三体衰变（β 衰变）：**

  - 母核衰变后生成了**三个**产物：**子核 + β 粒子（e- 或 e+） + 中微子
    $$
    \bar{\nu}_e 或 \nu_e。
    $$

  - 反应方程为：

    - $$
      \beta^- 衰变：\text{n} \rightarrow \text{p} + \text{e}^- + \bar{\nu}_e
      $$

      

    - $$
      \beta^+ 衰变：\text{p} \rightarrow \text{n} + \text{e}^+ + \nu_e
      $$

2. 能量的“随机连续分配”机制

在每次 β 衰变事件中，衰变产生的总可分配能量（即衰变能 Q 值）是固定的。由于子核质量极大，它带走的反冲动能可以忽略不计，因此**总衰变能 Q 几乎完全由 β 粒子和中微子两者平分**：
$$
Q \approx E_{\beta} + E_{\nu}
$$

- **能量分配的随机性：** 尽管两者能量之和等于常数 $Q$，但动量守恒只约束了三个物体的矢量和为零，**并没有限制 β 粒子与中微子各自能分到多少能量**。

- **分配概率的连续性：**

  - 在极罕见的情况下，β 粒子带走了几乎全部能量
    $$
    E_{\beta} \approx Q
    $$
    此时中微子能量接近 0。

  - 在另一种极限情况下，中微子带走了几乎全部能量，β 粒子的动能接近 0
    $$
    E_{\beta} \approx 0
    $$

  - 在绝大多数情况下，两者在 0 到 Q 之间以某种概率**任意比例瓜分**这些能量。

因此，探测器对大量衰变事件中的 β 粒子进行统计时，就会测到一个能量从 0 连续延伸到最大值 Q（端点能量 E_{\max}）的**连续曲线**。

# How

### 利用重核的自发裂变作为一种高能重离子标准放射源

以最常用的自发裂变源 
$$
^{252}\text{Cf}
$$
**（锎-252）** 为例，利用其特性的方法和注意事项如下：

**高能重离子标定**：自发裂变产生的裂变碎片是质量数较大（如 A ~ 108 和 143）、带有高有效电荷且动能极高（75-110 MeV）的重离子。这填补了常规 α源（通常仅 4-6MeV）无法覆盖的高能重离子标定区间。 

**利用“双峰”能谱进行双点校准**：裂变碎片的能量谱呈现出特征性的“双峰”结构（重碎片峰约 80MeV，轻碎片峰约104MeV）。利用这两个已知峰值的位置，可以一次性对探测器的高能段响应进行多点校准。

**超薄衬底与源层**：由于重离子在固体物质中的射程极短、能耗极高，为了防止“自吸收”导致能量谱畸变，自发裂变源必须制备得极薄（通常蒸镀在薄膜或平整基底上）。

**考虑单侧逃逸效应**：在平整衬底上的自发裂变源，每次裂变产生的两个反向飞出的碎片中，只有一个能向外飞出进入探测器，另一个会被衬底吸收。

**扣除 α 粒子背景**：$^{252}\text{Cf}$ 同时存在高概率的 α 衰变（衰变率远高于自发裂变）。在数据处理或硬件触发时，需利用能量阈值将低能的 α信号（6MeV）与高能的裂变碎片信号（>70MeV）区分开。

### 特征X射线的产生原理

- **激发与退激发过程：** 当原子中的轨道电子受某种激发过程干扰离开原轨道时，原子会处于短暂的激发态。在固体材料中，电子会在 **$1\text{ ns}$（纳秒）或更短的时间内**重新排布，使原子返回能量最低的基态。   
- **能量释放形式：** 从激发态跃迁回基态所释放的能量，会以**特征 X 射线光子**的形式辐射出来。光子的能量严格等于**初态与末态之间的结合能差值**。   
- **谱线分类（$K_\alpha, K_\beta$ 等）：**
  - **$K$ 壳层空穴：** 若原子最内层的 $K$ 壳层暂时出现空位，其他壳层电子填补该空位时就会释放 **$K$ 系列特征 X 射线**。   
  - **$K_\alpha$ 光子：** 若填补 $K$ 层空位的电子来自相邻的 **$L$ 壳层**，产生的 X 射线称为 **$K_\alpha$ 光子**，其能量为 $E_{K_\alpha} = B_K - B_L$（即 $K$ 层与 $L$ 层的结合能之差）。   
  - **$K_\beta$ 光子：** 若填补的电子来自更外层的 **$M$ 壳层**，产生的 X 射线能量稍高，称为 **$K_\beta$ 光子**。   
  - **能量上限：** 当 $K$ 层的空位由一个自由（未结合）电子填补时，产生的光子能量达到 $K$ 系列的最大值，即直接等于 $K$ 壳层的结合能 $B_K$。   
  - **级联过程（$L, M\dots$ 系列）：** 外层电子填补内层空位后，自身原来的位置又留下了新的空位，随后会被更外层的电子填补，并伴随发射 $L$ 系列、$M$ 系列等特征 X 射线。

由于每种元素的原子核外电子结合能都是独一无二的，因此特征 X 射线的能量也是**该元素独有的“指纹”**，广泛用于未知样品成分的**元素分析（如 XRF 荧光光谱分析）**。
